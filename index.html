智造云链 · 工业采购多智能体系统 多智能体 · 采购供应链
面向智能硬件供应链场景，在既有采购、订单等 Java 微服务之上构建统一自然语言业务入口（AgentCenter），业务人员可通过自然语言完成供应商寻源、采购办理、履约查询及知识问答。架构由「单 Agent + 多 Tool」演进为基于 LangGraph 的路由式多智能体架构，并引入 A2A 与 MCP 协议实现 Agent 服务化与业务能力标准化。
PythonFastAPILangGraphLangChainPostgreSQLRedisSSEA2AMCPNacosGatewayRAG
▾
  • 多智能体编排与路由：基于 LangGraph StateGraph 构建 Intent、Sourcing、Procurement、Tracking、Knowledge 等专业 Agent，通过 RouteState 与 Conditional Edge 实现语义意图路由；各 Agent 严格隔离职责边界，仅暴露职责范围内 Tool，有效限制大模型写操作越权。
  • 状态管理与会话持久化：基于 MessagesState 保存真实业务对话，使用独立 intent 字段承载内部流程控制信息；通过 AsyncPostgresSaver 按 sessionId/thread_id 持久化与恢复 State，实现跨 Agent 多轮上下文保持及 AgentCenter 多实例间会话无缝恢复。
  • Tool Calling 与流式交互：将供应商、采购订单等原 Java 微服务能力封装为业务 Tool；请求级 user_token 通过运行上下文隐式传递，模型仅负责 Tool 选择与参数组织；通过 SSE 分离自然语言与结构化 Tool 结果，实现打字机效果并支持停止生成。
  • 微服务治理与并发控制：AgentCenter 作为 FastAPI 微服务注册至 Nacos，由 Gateway 统一完成认证、服务发现、令牌桶限流及熔断降级；基于 Redis 设计 sessionId 会话级互斥锁，避免同一用户并发请求导致上下文与业务操作错序。
  • A2A 与 MCP 架构演进：将本地专业 Agent 拆分为独立 A2A Agent 服务，由中心侧统一完成远程路由及流式事件桥接；进一步将通用业务 Tool 抽取为 MCP Server，大幅降低各专业 Agent 对底层业务接口实现的重复耦合。
  • KnowledgeAgent 与 RAG 落地：针对采购制度、物料规格等内部文档构建基础 RAG 链路（解析、切片、Embedding、向量 TopK 召回）；引入来源约束机制，在检索证据不足时避免生成无依据的专业事实，控制幻觉风险。
